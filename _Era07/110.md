ascend old solid stairs\
up to doors on the left\
Arts Reference Library

large long reading room\
empty tables and chairs\
light from high windows

neat catalogue drawers \
full of typed index cards\
ordered Dewey numbers

grey formica table top\
thick books that clunk\
leaf catalogue raisoné

tie off shirt open\
abandon school

this is learning\
library is home

quiet library lady\
look never asking \
why not in school
